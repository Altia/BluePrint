Issues are welcome for errors, ambiguities, or gaps in the specification and
examples.

Altia, Inc. maintains the specification and is the only publisher of modified
versions of it (see [README.md](README.md#licensing)). Pull requests are
accepted on the terms below.

addition to that license, Altia, Inc. permits you to publish a modified copy
in a fork or branch on GitHub, solely to propose those changes to this
repository by pull request. This permission does not cover publishing,
distributing or hosting the modified copy for any other purpose, such as
