# Altia BluePrint

Altia BluePrint (ABP) is a declarative language for describing human–machine
interfaces. This repository holds the language specification, the BluePrint
website, and example designs.

The website is published from the `docs/` folder at
**https://altia.github.io/BluePrint/**.

## Contents

| Folder | Contents |
|---|---|
| [docs/](docs/) | The BluePrint website, including the language reference |
| [demos/](demos/) | Example `.abp` designs |
